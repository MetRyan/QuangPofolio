# Thư mục hình ảnh Hành Trình Về Nguồn & Tu Tập

Bạn hãy đặt các hình ảnh tu tập (ví dụ tại Yên Tử cùng Thầy Pháp Nhật) vào thư mục này.
Định dạng khuyên dùng: `.jpg`, đặt tên từ `1.jpg` đến `10.jpg`.

Các đường dẫn tương ứng trong code sẽ là:
- `/assets/projects/retreat/1.jpg`
- `/assets/projects/retreat/2.jpg`
- ... và cứ thế tiếp tục.
